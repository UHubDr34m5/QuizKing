# QuizKing

GitHub Pagesの個人向けクイズサイトです。ホームの「本屋大賞」からモード選択に進みます。

## パーフェクト暗記モード

最初に「本屋大賞が始まった年は？」を西暦で回答します。2004年に正解すると、2004〜2026年の本屋大賞部門1位・23作品の表を表示します。不正解の場合はその場で終了します。

作品名・作者名は通常のテキスト入力欄です。スマホでタップすると端末標準のキーボードが開き、日本語変換は端末のIMEを使用します（日本語キーボードの設定・選択は端末側）。独自キーボード・変換辞書はありません。入力中に画面を再描画しないため、変換中の文字とカーソルを保ちます。

- 作品名は正式表記との完全一致。副題・句読点・半角数字を含み、巻数は含めません。「東京タワー」の本題と副題の間は半角スペースです。
- 作者名は姓と名の境界だけ半角・全角スペースを許可します。
- 下部の「解答する」で46欄を一括採点。空欄は不正解。結果の作品名から、あらすじと出典を確認できます。

## 神経衰弱モード

開始年の問題を経由せず、23作品の西暦・作品名・作者名の計69枚をシャッフルして開始します。3枚めくるごとに1トライ。同じ受賞作の西暦・作品・作者が1枚ずつ揃うと消えます。残りのカード位置は変えません。同じ作者名のカードは相互に利用できます（例：恩田陸、凪良ゆう）。

不一致の3枚は「次のトライ」を押すまで表示します。一致した3枚は短い確認時間後に消えます。判定中の追加選択、同じカードの重複選択、消えたカードの選択は無効です。

全69枚を揃えた時点の最少トライ数を `localStorage` に保存し、モード選択・ゲーム中・結果に表示します。途中終了は記録に含めません。保存キーには対象年一覧を含め、対象作品数が増えた場合は別の記録になります。保存不可・破損データでもゲームは継続します。

モード選択へ戻る・再読み込みで進行中の解答とゲームは終了します。自己ベストは同じ端末・ブラウザ内に保存され、他端末との同期はありません。ホームのステータスへの加算はありません。

## ファイルと確認

- `index.html`：ホーム
- `hontai-page.js`：画面切替（`#hontai` / `#hontai/perfect` / `#hontai/memory`）
- `hontai.js`：モード選択、入力、採点、神経衰弱画面
- `hontai-memory.js`：カード・トライ・記録のルール
- `hontai-data.js`：公式受賞情報とあらすじ・出典
- `hontai.css`：スマホ・タブレット・PCのレイアウト

`node --test tests/hontai.test.cjs` で採点、カード生成、同名作者の組合せ、トライ数、全消去、記録保存を検証できます。
