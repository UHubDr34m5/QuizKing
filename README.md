# QuizKing

GitHub Pagesの個人向けクイズサイトです。`index.html` がホーム画面、`hontai-page.js` がホームと本屋大賞クイズの画面切替を担当します。

## 本屋大賞クイズ

ホームの「本屋大賞」から開始。開始年（2004年）に正解すると、2004〜2026年の本屋大賞部門1位・23作品を古い順に出題します。開始年を間違えると終了します。表の作品名・作者名46欄は下部の「解答する」で一括採点し、空欄は不正解になります。結果の作品名から短いあらすじと参照元を開けます。

- 作品名は `hontai-data.js` の正式表記と完全一致（副題・句読点・半角数字を含む）。巻数は含めません。「東京タワー」の本題と副題の間は半角スペースです。
- 作者名は姓と名の境界だけ半角・全角スペースを許可。異体字・別名・読み仮名は正解にしません。
- 画面下部の独自キーボードは、中央／左／上／右／下へのフリック、濁点・半濁点・小文字、数字、空白、記号に対応。PCではマウスのドラッグでも操作できます。
- 「変換」は内蔵辞書による読みに対する完全一致変換です。収録作品・作者の全文と構成語句、ひらがな／カタカナを変換できます。汎用IMEのような任意文の漢字変換・予測補完はしません。入力内容は外部へ送信しません。
- 「確定」または候補選択で入力欄へ反映。カーソル矢印と削除で修正、「次の欄」で移動。採点直前・欄移動時も未確定文字を反映します。
- 本モードは静的な資料クイズです。ホームのステータスへの加算・記録保存はありません。再読み込みで解答はリセットされます。

追加ファイル：`hontai-data.js`（受賞情報・あらすじ・変換辞書）、`hontai.js`（進行・採点・入力）、`hontai.css`（画面）。次年度追加時はデータと作者名の姓境界定義、確認テストの対象年を更新してください。データの出典は各作品に記録しています。

採点・辞書の確認：`node --test tests/hontai.test.cjs`
