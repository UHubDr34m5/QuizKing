# QuizKing

GitHub Pagesの個人向けクイズサイトです。ホームの「本屋大賞」「元素」「年表」から、それぞれの学習画面へ進みます。

## パーフェクト暗記モード

最初に「本屋大賞が始まった年は？」を西暦で回答します。2004年に正解すると、2004〜2026年の本屋大賞部門1位・23作品の表を表示します。不正解の場合はその場で終了します。

作品名・作者名は通常のテキスト入力欄です。スマホでタップすると端末標準のキーボードが開き、日本語変換は端末のIMEを使用します（日本語キーボードの設定・選択は端末側）。独自キーボード・変換辞書はありません。入力中に画面を再描画しないため、変換中の文字とカーソルを保ちます。

- 作品名は正式表記との完全一致。副題・句読点・半角数字を含み、巻数は含めません。「東京タワー」の本題と副題の間は半角スペースです。
- 作者名は姓と名の境界だけ半角・全角スペースを許可します。
- 下部の「解答する」で46欄を一括採点。空欄は不正解。結果の作品名から、あらすじと出典を確認できます。

## 神経衰弱モード

2〜登録年数（現在23年）から年数を選択し、ランダムな受賞作の西暦・作品名・作者名をシャッフルして開始します。カードは選択年数の3倍です。3枚めくるごとに1トライ。同じ受賞作の西暦・作品・作者が1枚ずつ揃うと消えます。残りのカード位置は変えません。同じ作者名のカードは相互に利用できます（例：恩田陸、凪良ゆう）。

不一致の3枚は「次のトライ」を押すまで表示します。一致した3枚は短い確認時間後に消えます。判定中の追加選択、同じカードの重複選択、消えたカードの選択は無効です。

全カードを揃えた時点の最少トライ数を `localStorage` に保存し、ゲーム中・結果に表示します。途中終了は記録に含めません。題材と出題数ごとに記録を分け、全作品の出題では従来の保存キーを引き継ぎます。保存不可・破損データでもゲームは継続します。

モード選択へ戻る・再読み込みで進行中の解答とゲームは終了します。自己ベストは同じ端末・ブラウザ内に保存され、他端末との同期はありません。ホームのステータスへの加算はありません。

## ファイルと確認

- `index.html`：ホーム
- `hontai-page.js`：画面切替（`#hontai` / `#hontai/perfect` / `#hontai/memory`）
- `hontai.js`：モード選択、入力、採点、神経衰弱画面
- `hontai-memory.js`：カード・トライ・記録のルール
- `hontai-data.js`：公式受賞情報とあらすじ・出典
- `hontai.css`：スマホ・タブレット・PCのレイアウト

`node --test tests/hontai.test.cjs` で採点、カード生成、同名作者の組合せ、トライ数、全消去、記録保存を検証できます。

## 元素

原子番号1〜118を登録。パーフェクト暗記は開始・終了番号を選び、元素記号と名前を入力します。記号は大文字・小文字を区別します。神経衰弱は2〜118種類を選び、原子番号・元素記号・名前の3枚を揃えます。データは `elements-data.js`。

## 年表

`#timeline` で全登録出来事を年ごとに表示します。上が新しく下が古く、タグで絞り込めます。同日公開作品の重なりを避けるため、縦の間隔は経過時間に比例しません。年表の上に「並び替えモード」を置いています。`#timeline/sort` では枚数の代わりにタグを選び、そのタグの全出来事をシャッフルして出題します。上下ボタンまたは移動先の番号で並び替え、「答え合わせ」で上から日付の降順なら成功。同日の出来事の前後は問いません。不正解時は配置を維持して再挑戦でき、正解時に日付を表示します。1件だけのタグは年表で閲覧できますが、並び替えには2件以上必要です。

- `timeline-data.js`：全69件。追加時は一意のid、表示文言、YYYY-MM-DD形式の日付と複数のタグ（例：`tags: ['映画', 'ジブリ']`）を登録します。タグの選択肢・件数・出題対象へ自動反映します。`dateEnd` は複数日の表示用で、並び替えは開始日基準。任意の `source` と `note` は年表の補足・出典に表示します。
- `timeline.js`：年別表示、タグ選択、シャッフル、並び替え、判定。
- `timeline.css`：スマホ・タブレット・PC表示。

映画は日本での初回劇場公開日（2026年9月29日確認）。PIXAR公式長編一覧の公開済み31作品と、ジブリ公式作品一覧の27作品（ナウシカ・海がきこえる・併映短編2作を含む）を収録。配信／テレビ放送日とは区別しています。ジブリは公式作品一覧、PIXARは公式長編一覧と公開日一覧を照合し、作品別の出典をデータに保持。『海がきこえる』の劇場公開日は映画.com、『トイ・ストーリー4』は公開元の発表に基づき2019年7月12日を採用しています。

本屋大賞の作品概要は `hontai-data.js` に3段落の独自要約と参照先を保持します。一覧と採点結果は同じ概要ダイアログを使います。

`node --test tests/*.test.cjs` でクイズの採点・抽選・年表の並び順を検証します。
